# 연구 방법

## 핵심 원칙: 사전 등록

모든 새 실험은 **돌리기 전에** 문서를 먼저 씁니다.

| 항목 | 내용 |
|---|---|
| 가설 | 기대하는 현상과 그 근거(논문·관찰) |
| 규칙 | 진입·청산·사이징을 하나로 고정 |
| 기준선 | 같은 기간·자본·비용의 비교 대상 (예: BTC 보유, 단일 MA200) |
| 데이터 분할 | 설계 구간 / 미사용 검증 구간 / 전진 구간 |
| 통과 조건 | 숫자로 된 조건. 하나라도 못 넘으면 "근거 부족" |
| 탐색 횟수 | 시도한 변형 수 — 다중 비교 할인에 사용 |

결과를 본 뒤에 기준을 바꾸면 그건 검증이 아니라 맞추기이기 때문입니다.

## 검증 흐름

1. **가설과 기준 고정** — 위 표를 결과 보기 전에 작성
2. **데이터 점검** — 출처·기간·시간대·결측·중복·*이용 가능 시점*. 지표 워밍업과 봉 마감, 신호 이후 체결 시점 명시
3. **설계 구간 백테스트** — 수수료·슬리피지·펀딩·차입 비용 반영, 기준선과 비교
4. **미사용 구간 검증** — 한 번만. 본 뒤 고친 전략은 그 구간을 다시 미사용이라 부르지 않음
5. **강건성** — 비용 2배, 주변 파라미터, 체결 지연, 연도별·국면별 성과, 한 해씩 빼고 다시 계산
6. **판정과 기록** — 채택·보류·기각과 그 이유. 실패한 실험도 남김

## 재현성

각 실험 산출물에는 다음을 남깁니다.

- 실행 명령, 코드 커밋, 미커밋 변경 여부
- 모든 입력 파일의 경로·**sha256 해시**·기간
- 유효 설정, 라이브러리 버전, 난수 시드
- 탐색 횟수와 검증 구간

## 과최적화를 막는 장치

| 장치 | 이유 |
|---|---|
| **Deflated Sharpe Ratio** | 50개 설정을 돌리면 엣지가 없어도 최고 샤프의 기댓값이 연 1.07 정도. 시도 횟수만큼 할인 |
| **탐색 / 판정 종목 분리** | 89종목을 탐색 49 / 판정 40으로 나눠, 고치는 건 탐색 종목에서 자유롭게, 판정은 판정 종목에서 한 번 |
| **연환산 지표 사용** | 7년 누적 수익/MDD("MAR 25~29")는 과장돼 보임 → 연환산 CAGR/MDD(약 0.96)로 다시 계산 |
| **표본 수 계산** | 눌림목 OOS 거래당 +0.30% / 편차 2.03% → 유의성 80% 검정력에 289건(7년) 필요. 통계적 유의성을 기다리는 대신 판정 기준을 "백테스트 재현성"으로 정함 |
| **데모는 판정 도구가 아님** | 전진 기록은 공개 시세로 다시 계산해서 잼 |

## 데이터 함정에서 배운 것

- **베이시스 시계열의 절반이 원월물이었다.** 수집기가 "오늘의 근월물" 하나로 과거를 통째로 재는 구조였고, 만기된 분기물은 상장폐지돼 다시 받을 수 없었습니다. 이후 `validate` 명령으로 오염 구간을 표시합니다.
- **거래소가 최근 구간만 주는 데이터**(포지셔닝 30일 등)는 덮어쓰면 과거가 영영 사라집니다 → 모든 수집기를 병합 저장 방식으로 통일.
- **우리 ATR은 표준이 아니었다.** TR의 단순이동평균이라 Wilder 평활과 봉의 72.7%에서 5% 이상 달랐습니다.

| 탐색 횟수 | 기본 1 + 비용 1 + 주변값 6 = 8 변형 |
