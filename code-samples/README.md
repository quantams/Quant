# 코드 샘플

[← README](../README.md)

원본 비공개 저장소(Quant Trading, C#)에서 **전략 판단과 무관한 인프라 코드**를 그대로 가져온 발췌본입니다.
다른 프로젝트의 타입을 참조하므로 이 폴더만으로는 빌드되지 않습니다.

| 파일 | 무엇을 보여 주나 |
|---|---|
| [ArchitectureTests.cs](ArchitectureTests.cs) | 계층 구조를 문서가 아니라 테스트로 고정하는 방법 (ArchUnitNET). 프로젝트 참조 허용 목록, "판단 코드는 파일·네트워크 금지", "대시보드는 주문 인터페이스 금지" |
| [Sleeve.cs](Sleeve.cs) | 한 계좌를 여러 전략이 나눠 쓸 때의 몫 장부. 실제 사고(다른 전략의 돈으로 BTC를 산 일)에서 나온 설계와, 모르는 가격을 0으로 치지 않는 규칙 |

두 파일 모두 주석이 한국어로 "무엇"보다 **"왜"**를 설명합니다 — 사고에서 나온 규칙은 그 사고를 같이 적는 것이 이 코드베이스의 원칙입니다.
